# Coop's Maths Lab

A daily maths and problem-solving trainer for Years 4–6, built around the NSW Mathematics K–10 Syllabus (2022) Stage 3 outcomes. Questions are generated by the app itself. It needs no account, no login and no AI, and it works offline once installed.

## Put it online with GitHub Pages (one-off, about 10 minutes)

1. **Create a free GitHub account** at https://github.com/signup. Use your own (adult) email.
2. **Create a repository:** click **+** (top right), then **New repository**.
   - Name: `maths-lab` (any name works; it becomes part of the web address)
   - Choose **Public**. Free accounts can only publish Pages from public repositories. Only the app's code is public. Cooper's progress never leaves his iPad.
   - Click **Create repository**.
3. **Upload the files:** on the new repository page, click **uploading an existing file**. Drag in all of these files, then click **Commit changes**:
   `index.html`, `engine.js`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` (this README is optional)
4. **Turn on Pages:** go to **Settings**, then **Pages** (left menu). Under *Build and deployment*, set **Source: Deploy from a branch**, **Branch: main**, folder **/ (root)**, then click **Save**.
5. Wait 1–2 minutes and refresh the Pages screen. Your address appears at the top:
   `https://YOUR-USERNAME.github.io/maths-lab/`

## Put it on Cooper's iPad

1. Open the address above in **Safari**. It must be Safari for the home-screen install.
2. Tap **Share**, then **Add to Home Screen**, then **Add**.
3. Open it from the home-screen icon. It runs full screen like an app, and works without internet after the first open.

## Good to know

- **Progress lives on the iPad**, inside the home-screen app. Deleting the icon deletes the progress. Use **Grown-ups**, then **Make backup code**, now and then, and paste the code into Notes or an email.
- **Grown-ups PIN:** set one in Grown-ups, then Settings, so Cooper can't change his own levels.
- **Updating the app:** upload the changed files to the same repository (**Add file**, then **Upload files**, then **Commit**). The iPad picks up the new version the next time it opens with internet. Progress is kept.
- **Levels:** Year 4 = late Stage 2, Year 5 = Stage 3, Year 6+ = extension. Each skill moves up after 4 of the last 5 are right without much help, and down after a run of misses.
